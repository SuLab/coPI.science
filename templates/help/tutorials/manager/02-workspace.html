What it means

Signing in

You sign in with ORCID, using the ORCID iD your account was created with. A manager lands on the PIs page, unless you were trying to open another page before signing in: sign-in then takes you to that page instead.

{% if microsoft_sign_in %}

Microsoft sign-in is a second way in once it is linked. The Microsoft sign-in section of Settings asks you to confirm it's you by signing in with ORCID again, then offers Link Microsoft account. Until a Microsoft account is linked, sign in with ORCID. See Microsoft sign-in.

{% endif %}

The tutorial prompt

Until you answer it, Workspace pages open with a box headed New to Blackbird? offering Start the tutorial and Don't show again. Starting the tutorial records nothing. Don't show again, or Finish on the last step of this tutorial, stops the box for good; the tutorials stay under Help.

The Workspace tabs

Workspace opens the PIs page, and a row of tabs under the top bar leads to the rest:

  • PIs: every PI, with profile and lab bot status, and the Add PI form.
  • Assessments: the hub's assessments of lab pitches, to read, review and assign.
  • Slack Bots: every PI's lab bot and where it is in Slack setup.
  • Staff: manager, reviewer and admin accounts, and adding reviewers.
  • Discussions: the simulation's threads and how each ended.
  • Interviews: each simulation interview, one line per post.
  • Activity: simulation runs and their message statistics.
  • Prompt Suggestions: suggested prompt changes distilled from review feedback.

A reviewer sees only the PIs and Assessments tabs.

Settings

Settings holds your own account's Delete account link{% if microsoft_sign_in %} and the Microsoft sign-in section{% endif %}.

{% call careful() %}

Delete account deletes your own account. The page it opens explains what deleting does and asks you to type delete to confirm. It cannot be undone.

{% endcall %}

Signing out

Sign out signs you out on every device, not only the one you are using.

Help

The Help tab has an overview, the tutorials for your role and the reference pages. Many Workspace pages also carry a Help with this page link in their header, which opens the matching reference section. See Finding your way around.
