What it means

Discussions

Every thread started in the simulation, and how it ended.

  • Run: picks one simulation run or All Runs.
  • The status cards count the run's threads: No Replies, Active (replies, no outcome yet), and the recorded outcomes Proposal, No Proposal and Timeout. A card filters the table to that status; pressing it again clears the filter.
  • The filters narrow by channel, status and one or more agents; Clear removes them.
  • Each thread row shows its status, channel, who posted it, the reply count, who replied, the outcome and when it started. A row with more to show opens to reveal the outcome's summary and the Specialist panel cards: each specialist's signal, how many concerns it filed, its confidence, how its reply was read, and reply cut off when a reply stopped before it finished.

Only an admin can export Discussions or read a specialist's reply verbatim.

Activity

The Agent Activity page opens with cards for the number of simulation runs, total messages, channels created and the most active agent. The Simulation Runs table lists each run's start, end, status, messages, API calls and configuration. A run opens its Simulation Run page: its message, API call and channel counts, messages by agent and by channel, the channels created, and a message timeline that shows who posted, where, when and how long each message was, never the message text. Only an admin sees a run's model-call logs and the controls for stopped runs.

Prompt Suggestions

Suggested changes to the simulation's prompts, distilled from review feedback marked Learn. Nothing on this page ever changes a prompt file.

  • Generate suggestions from current reviews queues an analysis for each assessment whose Learn feedback no suggestion has used yet. The line under it says how many are eligible, or Nothing to analyse. One press analyses only a limited number, which that line states when it applies; pressing again continues with the rest. The analyses run in the background, and the page shows new suggestions once they finish and the page is reloaded.{% if permissions.admin %} The button is hidden while an admin is viewing the site as someone else.{% endif %}
  • Status: filters the list by Open, Dismissed or Implemented.
  • A suggestion's subject opens its page: the Suggested Change, the Raw model response, the feedback it was Distilled From, and the Prompt Files Read, each marked current, STALE (the file has changed since) or file missing. Reopen, Dismiss and Mark Implemented set its status.
{% call careful("Careful: Generate suggestions from current reviews") %}

Each press queues real analyses by a large model, which cost money, and they cannot be cancelled from the page. A second press while earlier ones are still queued does not queue those assessments again.

{% endcall %} {% call careful("Careful: suggestion status") %}

Reopen, Dismiss and Mark Implemented only record who set which status. They never edit a prompt file, and setting another status replaces them.
