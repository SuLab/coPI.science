What it means

The page lists every PI lab bot and where it is in Slack setup. The header counts the bots that are active, pending and muted, and any in another state.

  • PI links to the PI's page. A bot with no linked PI account shows the PI's name with (no linked PI) and no actions.
  • Bot is the lab bot's name and its short identifier.
  • Status is Active, Pending or Muted; any other status, such as Suspended, is shown by name.
  • Slack token says installed once the Slack bot is installed, else not installed.
  • Actions holds the one next step for the bot: Install Slack bot for a pending bot without a token, Activate for a pending bot with one, Mute for an active bot and Unmute for a muted one. A bot in any other state shows only its status; only an admin can manage it.

These are the same controls as on the PI's page, with the same checks, and each lands on that PI's page afterwards, with any refusal at the top — except Install, which goes through Slack's install screen; if the install fails or is cancelled there, you land on the PIs list with the message instead.

{% call careful("Careful: the actions on this page") %}

Install Slack bot creates a real Slack app for the PI and starts Slack's install; nothing in the Workspace removes it. Activate puts the bot on the running simulation's roster at its next roster sync; Mute takes it off and Unmute puts it back, each undoing the other.
