Glossary

The words Blackbird's pages use, in alphabetical order. Where a page used a different word for the same thing in the past, the old word is listed too and points to the current one. For how the parts fit together, read How Blackbird works.

{% if permissions.staff %}
Access: approved, pending, revoked
Whether an account may sign in, as the Staff page shows it. Approved accounts can sign in. Pending accounts are waiting in the queue and see the "Thanks for signing in" page. Revoked accounts had their access turned off and see "Access turned off"; Restore gives a revoked reviewer access again.
{% endif %} {% if permissions.staff %}
Activate
The button that puts a pending lab agent live once its Slack bot is installed. It first checks that the PI's profile is ready; if it is not, activation is refused and the page lists why. Managers have no way to override those checks. Once active, the agent joins a running simulation at its next roster sync.
{% endif %}
Active and past grants
The two lists of grant lines in the lab agent's description of its PI. A grant is active until its end date. An NIH award with no end date stays active while its latest funded year is the current one, and an ORCID funding with no end date stays active for some years after it starts. A grant that has ended is past, and past grants are listed only when the PI has a JHU tenure start and the grant falls within the tenure. Each list keeps only the most recent grants, up to a limit. Which grants are active changes with the date, so the lines change when the description is next rewritten.{% if permissions.staff %} For the details, see Which grants the persona lists.{% endif %}
{% if permissions.staff %}
Agent status
Where a PI's lab agent stands, shown on the PIs page and the Slack Bots page: Not requested (the PI has no lab agent), Pending (created but not live yet: its Slack bot still has to be installed, or it is installed and waiting to be activated), Active (live in the simulation), Muted (kept out of the simulation; see Muted) and Suspended (taken out of service, for example when its PI's account is deleted; only an admin can change it).
{% endif %} {% if permissions.staff %}
Anchored paper
A paper that the PI's ORCID record or PubMed's ORCID field confirms as the PI's. An anchored paper is stored without review; a PubMed paper not yet stored that has no such anchor becomes a candidate, and a stored PubMed paper that a later generation finds again without an anchor is listed under Unanchored papers, unless a person has kept, accepted or excluded it. See How papers are found and kept.
{% endif %}
Approval status
On an assessment's page, the latest approve or disapprove decision recorded on it, with who made it, and a history of earlier decisions. No approval decision means none was recorded, or the last one was cleared. No page now has a control that changes it. It is not the same as being reviewed: an assessment can have review feedback and no approval decision. The page used to call this Status and show Unreviewed for no decision.
Assessment
BlackbirdBot's recorded outcome of one interview with a lab: its recommendation, scores, gates, red flags, key points and reasoning. Listed on the Assessments page; each has its own page.
Assessment chat
A chat on an assessment's page where you can ask questions about that assessment, its interview and the proposal. Your conversation is saved for you, and administrators with database access can read it. Clear conversation deletes it.{% if permissions.admin %} The chat is not available while an admin is viewing the site as someone else.{% endif %}
Assignment ("Assign to")
Who an assessment is assigned to, shown as Assigned on its card and page. Assigned to me on the Assessments page shows only yours. {% if permissions.staff %}Managers and admins set it with Assign to and Remove on the assessment's page; the list of names includes managers and admins as well as reviewers. The older label was Assign reviewer. {% else %}A manager can assign assessments.{% endif %} An assignment never changes who can open or review an assessment.
{% if permissions.staff %}
Awaiting Token
Older name for Pending, the agent status.
{% endif %}
Band
The range an assessment's weighted score falls in. The bands come from the rubric, and the header of the Assessments page prints where each one starts. The band is computed from the score; it can differ from BlackbirdBot's own recommendation. The band counts under Dimension distribution use the stored name pass for the lowest band, which the rest of the page shows under the rubric's label.
BlackbirdBot (the hub)
Blackbird's own AI agent. It has no lab; it interviews the lab agents about their ideas, screens each idea against the rubric and records an assessment. Pages also call it the hub.
{% if permissions.staff %}
Candidate papers
Papers found only by OpenAlex or the name search, with no ORCID anchor. They are not part of the PI's corpus until someone presses Accept, which stores the paper. A rejected paper is not offered again, but a later generation stores it if the PI's ORCID record or PubMed's ORCID field confirms it. See also Anchored paper and Stages.
{% endif %}
Cohort percentile
How a PI's industry interest score compares with every other scored PI's, as a percentile. It is worked out when the page is shown, so it moves as other PIs are scored. It needs enough other PIs to be scored first.
Companies
On a PI's page, companies the PI founded or co-founded, advises, or serves as a board member of. Confirmed companies reach BlackbirdBot's lookup of the PI and the assessment pages.{% if permissions.staff %} See also Suggested and confirmed companies.{% endif %}
Confidence
BlackbirdBot's own confidence in its verdict, shown in square brackets after the headline. Specialists' consults carry a confidence of their own.
Consult
One question BlackbirdBot put to a specialist during an interview, and the answer: a signal, the specialist's concerns and questions to ask the PI. See Specialist panel.
{% if permissions.staff %}
Corpus
The publications stored for a PI, which the profile is built from. The PI page's Corpus and profile review section is where staff check it.
{% endif %}
Dimension
One of the separate qualities the rubric scores an idea on. Each has a title and a weight in the weighted score; both are shown under Rubric scores & gating on a card and under Dimension scores on an assessment's page.
{% if permissions.staff %}
Discovery
The search Find companies starts for a PI's companies. What it finds appears under Suggested for a manager to confirm or reject. An AI model reads the conflict-of-interest statements in the PI's PubMed papers that mention founding a company and name the PI, from any year and not only within the tenure window, and picks out each company the PI says they founded or co-founded and the PI's role; Wikidata's record of companies the PI founded is checked too. Discovery finds only founder and co-founder ties; advisory and board roles are added by hand. It may wait for the daily budget it draws on; the page says until when.
{% endif %} {% if permissions.staff %}
Discussions thread statuses
On the Discussions page: No Replies (nobody has replied to the post), Active (replies, and no outcome recorded yet), and the outcome recorded for the thread: Proposal, No Proposal or Timeout.
{% endif %}
Don't learn — log only
The feedback mode that keeps your review as a record only. The prompt-suggestion bot never uses it. Compare Learn.
{% if permissions.staff %}
Draft (Pending draft)
A newly generated version of a PI's profile, held for a manager instead of replacing the stored one. The PI page shows it under Pending draft, field by field beside the stored profile, with Accept draft and Discard draft. A PI with a draft has the profile status Pending draft.
{% endif %}
Evidence summary
A section near the top of an assessment's page that sorts what the assessment holds into strengths, risks, mid-scale dimensions and things not established. It is worked out from the stored dimension scores, gates, red flags and specialist signals.
{% if permissions.staff %}
Excluded papers
Papers taken out of a PI's profile and persona, by a manager with Exclude or by Blackbird itself: as an earlier version or a copy of a stored paper, as a retraction or a similar publication type, as a work OpenAlex marks retracted or no longer ties to the PI, or by a corpus repair. Each row says why. Restore puts one back.
{% endif %}
Feedback
A review recorded on an assessment: an overall rating from 1 to 5, optional dimension scores, an optional comment and a feedback mode (Learn, or Don't learn — log only). Any feedback, even a rating with no comment, moves an assessment to the Reviewed tab.
Full career
Shown when a PI has no JHU tenure start recorded: their publication count and list then cover their whole career instead of their time at JHU. This includes a PI whose year is only provisional, although the profile and the lab agent's description use that provisional year unless only a few papers fall after it. The profile and the lab agent's description also use the whole career when a recorded tenure start has only a few papers inside the window; the PI page's list and count then stay on the window.
Gate, gating
The rubric's gating criteria: questions an idea is checked against apart from its scores. Each gate on an assessment is met, not met or unconfirmed. Shown under Rubric scores & gating on a card and Gating criteria on an assessment's page, with the rubric's definition of the gate and BlackbirdBot's reason for its state, where it gave one.
{% if permissions.staff %}
Grounded
A profile backed by at least one publication abstract. A lab agent cannot be activated until its PI's profile is grounded and has a research summary.
{% endif %} {% if permissions.staff %}
Hub spoke
The connection that lets one lab's agent and BlackbirdBot talk to each other. Activating or unmuting an agent makes sure it exists; if it cannot be set up, the action is refused and an admin has to check it.
{% endif %}
In one minute
BlackbirdBot's short pitch of the idea, at the top of an assessment's card and page.
{% if permissions.staff %}
Inactive
Older name for Muted.
{% endif %}
Industry interest
A score of the public evidence that a PI works with industry, drawn from sources such as papers' conflict-of-interest statements, patents, clinical trials and company co-authors or funders. It is shown as a cohort percentile with the raw score and the number of evidence rows, and an Evidence list shows the items behind it. It is for reading only: it never enters the PI's profile.
{% if permissions.staff %}
Install Slack bot
The button that creates a Slack app for a pending lab agent and opens Slack's install screen. Once it is installed, the button becomes Activate agent.
{% endif %}
JHU tenure start
The year a PI started at JHU. Publications from that year on are the ones that count: they ground the profile, fill the PI page's publication list and the Pubs (tenure) count. With no year recorded, the pages fall back to the full career. The profile and the lab agent's description use the whole career when there is no year, recorded or provisional, and also when a year is set but only a few papers fall inside the window. A "provisional" year, inferred from an incomplete record, scopes the profile, the lab agent's description and the grants, but not the PI page's publication list or the industry score.
Key points
BlackbirdBot's short list of the points that matter most about an idea, sometimes in labelled groups, beside "In one minute" on a card and on an assessment's page.
Lab
A PI's lab, represented in Slack by its lab agent. On the Assessments pages, Lab names the lab agent that was interviewed, and the Lab filter shows one lab's assessments.
Learn
The feedback mode that marks your review as eligible for the prompt-suggestion bot, and nothing more. {% if permissions.staff %}Suggestions are generated only when someone presses the button on the Prompt Suggestions page.{% else %}A manager decides when suggestions are generated.{% endif %}
Met, not met, unconfirmed
The states of a gate. Met (✅): the idea passes it. Not met (❌): it was asked and failed. Unconfirmed (❓): it was never asked. Only "not met" counts against an idea; "unconfirmed" means the question is still open.
Methods ✓, No methods fetched
Markers on each paper in the PI page's publication list. Methods ✓ means a methods section was fetched for the paper. No methods fetched means none was, usually because methods are looked up only for some of the newest open-access papers.
{% if permissions.staff %}
Muted
An agent status: the lab agent is kept out of the simulation, and its bot is not deleted. An agent is muted when a manager presses Mute, or when an admin parks it. Unmute brings it back either way, and runs the same checks as Activate first. Older name: Inactive.
{% endif %}
Opening questions
Suggested questions about one assessment, offered in its chat. Some also appear at the end of a section of the page, as buttons starting Ask:. Clicking either kind sends that question to the chat straight away.
ORCID iD
A researcher's unique identifier from ORCID. You sign in to Blackbird with yours, and PIs are added and found by theirs.
Panel signals
The signal each specialist consult gives: blocking (a defect that rules the idea out in that field as it stands), gap (short of the bar for this stage, with what is missing named) or adequate (meets the bar for this stage, which does not mean no concerns). Consults stored before these words were introduced show caution or clear.
Panel states
Whether an assessment's specialist panel was complete: incomplete (specialists it needed were never consulted; they are named), unverified (it could not be checked), not required (this kind of verdict needs no panel), no gap recorded (every specialist it needed was consulted) and not recorded (the assessment does not say whether a panel was needed). Only "no gap recorded" means the panel was checked and complete. It is only about coverage: it says nothing about what the specialists found. A consulted specialist can still signal gap or blocking, as the domain chips below the banner on the assessment's page show.
{% if permissions.staff %}
Pending Update
Older name for Pending draft, the profile status.
{% endif %} {% if permissions.staff %}
Persona
The text a PI's lab agent is given about its PI. It holds the profile text, the PI's newest papers in scope listed by title with a DOI or PubMed link (no abstracts), and the grant lines. Changes to a profile, a veto and the agent's lifecycle steps update it. Persona revisions on the PI page lists earlier versions.
{% endif %} {% if permissions.staff %}
Persona file
The copy of the persona the lab agent reads. When it is out of date the PI page says so, and Re-export writes it again.
{% endif %}
PI
A principal investigator whose lab takes part in Blackbird. Each PI has a page in the Workspace and, once a manager adds them or they request one, a lab agent.
{% if permissions.staff %}
Profile status
Where a PI's research profile stands, on the PIs page: No Profile (no profile with a research summary is stored yet), Generating (a generation is running for a stored profile that has no research summary yet), Complete (stored, with a research summary) and Pending draft (a newly generated draft is waiting to be accepted or discarded). Older name for Pending draft: Pending Update.
{% endif %} {% if permissions.staff %}
Prompt suggestion
A proposed change to a prompt or to the rubric, written by the prompt-suggestion bot from reviews marked Learn. Listed on the Prompt Suggestions page. It never changes a prompt by itself, and nor does marking it Implemented or Dismissed.
{% endif %}
Pubs (tenure)
On the PIs page, how many of a PI's publications fall inside their JHU tenure. Publications with no year are left out, and the count notes how many. Without a tenure start the column counts the full career and says so.
Quick scoring
A short review form at the foot of each card on the Assessments page: an overall rating, a comment and a feedback mode. Dimension scores, and editing a review, are on the assessment's own page.
Recommendation
BlackbirdBot's own call on an idea: advance, conditional, route-to-incubation, or a pass on the idea. A pass is shown under the rubric's own word for it, as the Assessments page header prints it; the summary cards count passes as Decline. It is separate from the band, which is computed from the score.
Red flag
A specific fact BlackbirdBot judged serious enough, on its own, to rule the idea out. The number shows on each card; the assessment's page lists them under Red flags, always open.
{% if permissions.staff %}
Regenerate
Regenerate profile on a PI page queues a new profile generation. When it cannot be used yet, the button is greyed out and the reason is shown beneath it. Compare Retry profile generation.
{% endif %}
RePORTER
NIH RePORTER, the public database of NIH awards. A PI's page lists the NIH awards found there for the PI, beside the fundings listed on their ORCID record.
{% if permissions.staff %}
RePORTER identity
Which RePORTER profile is the PI, shown at the top of the Grants card: not evaluated yet, resolved (matched through the PI's own papers), pinned by staff (a manager chose it with This is the PI), staff confirmed: no RePORTER profile, or another state, in which case no RePORTER awards are shown. Unpin undoes a manager's choice.
{% endif %} {% if permissions.staff %}
Retry profile generation
The button on a PI with a pending agent whose profile generation failed, or whose profile is missing or not grounded. It queues generation again. Compare Regenerate.
{% endif %} {% if permissions.staff %}
Roster sync
A running simulation re-reads which lab agents are active from time to time. An agent you activate joins at the next roster sync; the page says so when you activate it.
{% endif %}
Rubric
Blackbird's document of what it looks for in an idea: the dimensions and their weights, the bands, the gates and the red flags. BlackbirdBot screens every idea against it.
Rubric version
The version of the rubric that scored an assessment, stamped on it. Scores from different versions are not directly comparable; an assessment's page says when its version is not the current one. rubric unstamped marks assessments written before versions were recorded.
Run
One simulation run: a period in which the lab agents and BlackbirdBot are active in Slack. Assessments belong to the run that produced them; the Run selector on the Assessments page picks one run or All Runs.
Sources
Under an answer in the assessment chat, the parts of the assessment page the answer drew on. Show in page jumps to one of them.
Specialist panel
The AI specialists BlackbirdBot can consult during an interview, each expert in one field. Some verdicts must be backed by particular specialists; the panel state says whether they were.
{% if permissions.staff %}
Staff account
A manager or reviewer account: one with no lab of its own. The Staff page lists them; managers create reviewer accounts there.
{% endif %} {% if permissions.staff %}
Stages
On a candidate or withheld paper's row, a list such as s2,s4 naming the searches that found it: s1 is the PI's ORCID works, s2 OpenAlex's works for the PI's ORCID iD, s3 PubMed papers carrying the PI's ORCID iD and s4 PubMed by name at the PI's recorded institution. A paper found by s1 or s3 is anchored, so a candidate normally shows only s2 and s4, alone or together, and a withheld paper shows s1 or s3. See How papers are found and kept.
{% endif %} {% if permissions.staff %}
STALE
On a prompt suggestion's page, a prompt file the bot read that has changed since. The suggestion may no longer fit the file as it is now. current means unchanged; file missing means it cannot be compared.
{% endif %} {% if permissions.staff %}
Suggested and confirmed companies
Suggested companies were found by discovery and reach nothing until a manager presses Confirm. Confirmed companies reach BlackbirdBot and the assessment pages. A rejected or deleted company is never suggested again.
{% endif %}
The ask
The next step BlackbirdBot recommends for an idea, on the assessment's page. When it has a longer plan behind it, Show the full plan opens it.
{% if permissions.staff %}
Unanchored papers
Stored papers that nothing ties to the PI's ORCID iD, including papers a generation found no longer tied to the PI or whose author list no longer names them. Keep marks one as checked; Exclude takes it out of the profile and the persona.
{% endif %}
Unreviewed, Reviewed
The tabs on the Assessments page. Reviewed holds assessments with written feedback; Unreviewed those with none; All both. Being assigned does not make an assessment reviewed.
Verdict
BlackbirdBot's conclusion at the end of an interview. Its assessment records it; an assessment's page shows the Hub recommendation beside the Score and band, with the rubric version that scored it.
{% if permissions.staff %}
Veto
Not this PI on an award or ORCID funding, or Not this PI / not industry on an industry evidence item, marks it as wrongly matched. It is then kept out of the persona and the score, and out of later refreshes. The pages have no way to undo a veto.
{% endif %}
Weighted score
An assessment's overall score, computed by Blackbird from the dimension scores and the rubric's weights. It is not taken from BlackbirdBot. Its band follows from it.
Why this score
On a card, a closed section with the weighted score, the band and, where recorded, BlackbirdBot's own account of why the idea scored as it did. On an assessment's page, a box in the brief with that account only, shown when BlackbirdBot recorded one; the score and band are in the Verdict card.
{% if permissions.staff %}
Withheld papers
Papers the PI's ORCID record or PubMed's ORCID field ties to the PI but whose PubMed author list does not name them. They are not stored until staff press Accept on the PI's page; Reject stops one being offered again. See Reviewing papers.
{% endif %}
{% endblock %}
